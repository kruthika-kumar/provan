# Security

Repository URLs containing credentials and unsafe Git protocols are rejected. Full commit object IDs are required; mutable refs are rejected. Git runs with isolated HOME/configuration, prompts disabled, hooks disabled, object replacement disabled, LFS smudging disabled, and no repository code execution. Object-store alternates and symlinks are rejected. Object count, repository bytes, tree entries, tree output, and command duration are bounded and fail closed. Treat receipts as potentially sensitive and review them before sharing.

`PROVAN_HOME` is the exact state root; when unset it defaults to the user's `.provan` directory. Outputs and pending telemetry live at `<PROVAN_HOME>/outputs` and `<PROVAN_HOME>/pending`. POSIX writes use descriptor-relative directory traversal, no-follow opens, exclusive leaf creation and file/directory sync where supported. Windows rejects reparse-point components, device namespaces and alternate streams, uses create-new leaves and verifies the resulting path. Python does not expose a fully descriptor-relative Windows traversal, so a privileged concurrent reparse swap remains a residual TOCTOU limitation rather than a claimed POSIX-equivalent guarantee.
